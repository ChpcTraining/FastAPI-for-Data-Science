# FastAPI for Data Science

## From Python Websites to a CSV Data Viewer & Plotter

This tutorial series introduces FastAPI through a practical data-science project.

### Learning path

1. Your First FastAPI Website
2. Creating HTML Pages
3. Passing Python Data to HTML
4. Introducing Pandas
5. Reading CSV Data
6. Displaying Dataset Information
7. Displaying a Data Table
8. Generating Statistics
9. Uploading a CSV
10. Receiving Uploaded Files
11. Reading Uploaded CSVs with Pandas
12. Creating a Results Page
13. Understanding the Application Flow
14. Adding Plots
15. Serving Static Files
16. Creating Your First Plot
17. Letting the User Choose Columns
18. Final Project — CSV Data Viewer & Plotter

### Final project

The completed application will let a user:

- Upload a CSV file
- Inspect rows and columns
- Preview the dataset
- View descriptive statistics
- Choose columns
- Select a plot type
- Generate a visualisation

### Recommended prerequisites

Students should know basic Python including variables, functions, lists and imports. Basic Pandas experience is helpful but not required.
