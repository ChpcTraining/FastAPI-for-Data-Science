# FastAPI-for-Data-Science

From Python to a CSV Data Viewer & Plotter
Goal
In this tutorial you will learn how to use FastAPI to build a simple web application with Python.
You will start with a basic web page and gradually add:
- URL routes
- HTML templates
- CSS
- Pandas
- File uploads
- CSV processing
- Data summaries
- Data tables
- Data visualisation
- 
The final project will allow a user to:

Upload a CSV → inspect the dataset → view statistics → select columns → generate a plot
